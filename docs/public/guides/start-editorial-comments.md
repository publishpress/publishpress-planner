# Getting Started with Editorial Comments

Table of Contents

- [Enabling Editorial Comments](#h-enabling-and-disabling-editorial-comments)
- [How to Use Editorial Comments](#1-toc-title)
- [Finding Editorial Comments](#2-toc-title)
- [Notifying Other Users About Comments](#h-notifying-other-users-about-comments)

Please note: This feature is now deprecated because Editorial Comments are being added to the WordPress core.

One feature in the [PublishPress Planner](https://publishpress.com/links/planner) plugin is “Editorial Comments”. This allows you to leave private comments under posts in the WordPress admin area. These non-public comments allow for conversation between writers and editors. Normally this is used to discuss what needs to be changed before a post is published.

## Enabling Editorial Comments [#](#h-enabling-and-disabling-editorial-comments)

You can enable and disable comments by going to the “Features” tab in the [PublishPress Planner](https://publishpress.com/links/planner) settings:

![Enable and Disable Editorial Comments](https://docs-media.publishpress.com/publishpress-planner/editorial-comments-disable-232dc018d6.webp)

## How to Use Editorial Comments [#](#1-toc-title)

- Look below the post’s writing area and you’ll see “Editorial Comments”.

![The Editorial Comments metabox](https://docs-media.publishpress.com/publishpress-planner/add-editorial-comment-e6a9c97cd5.webp)

- Click the “Add an editorial comment” button.
- You will now be able to leave a comment. Click “Add Comment” when you’re done.

![Writing an Editorial Comment](https://docs-media.publishpress.com/publishpress-planner/editorial-comment-344d474231.webp)

It is possible to have comment threads, just as you would in a normal comments area. To make this work, click “Reply” next to a particular comment:

![Editorial Comments writing a reply](https://docs-media.publishpress.com/publishpress-planner/editorial-reply-fbf935197c.webp)

Here’s how the threaded comments will appear:

![Editorial Comments replies](https://docs-media.publishpress.com/publishpress-planner/editorial-comments-thread-8ea0f15aec.webp)

## Finding Editorial Comments [#](#2-toc-title)

All of the Editorial Comments on your site are visible via the “Editorial Comments” area in Planner menu.

![Finding Editorial Comments](https://docs-media.publishpress.com/publishpress-planner/editorial-comment-ebde230c65.webp)

## Notifying Other Users About Comments [#](#h-notifying-other-users-about-comments)

You can also choose who is notified about your comment by using the “Notify” box, on the right of the screen. The notification that is sent [can be customized using PublishPress Planner notifications](https://publishpress.com/docs/understanding-notification-workflow-screen/).

![Editorial Comments notifications](https://docs-media.publishpress.com/publishpress-planner/notify-in-wordpress-admin-beb1fd71d4.webp)
