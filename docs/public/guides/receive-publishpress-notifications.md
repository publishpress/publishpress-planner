# Get Planner Notifications by Email or Slack

Each user can decide where to receive the notifications from [PublishPress Planner](https://publishpress.com/links/planner). They can even choose to mute individual workflows.

By default, the notifications are sent by email. But you can extend that with the Slack integration in Planner Pro.

Each user can choose where to receive notification via this area of their user profile:
