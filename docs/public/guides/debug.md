# How to Use the Debug Feature in PublishPress Planner

Sometimes the PublishPress support team may ask you to send debug information. This helps us diagnose potential issues with your site and PublishPress.

- To enable the debug feature, go to Planner > Settings > Features in your WordPress menu.
- Check the “Debug” box.
- Click “Save Changes”.

![](https://docs-media.publishpress.com/publishpress-planner/debug-setting-a13c1b612f.webp)

- You will now see a “PublishPress Debug Log” link in the menu:

![](https://docs-media.publishpress.com/publishpress-planner/debug-log-link-bebbb5c9aa.webp)

You can now see the PublishPress debug data. You can copy-and-paste these details in your response to the PublishPress support team.

![](https://docs-media.publishpress.com/publishpress-planner/publishpress-logs-719e3b3ce7.webp)
