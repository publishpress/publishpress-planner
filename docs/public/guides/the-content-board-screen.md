# The Content Board Screen

Table of Contents

- [Introducing the Content Board Screen](#0-toc-title)
- [The Modal Editing Window](#1-toc-title)
- [Content Board Default Settings](#1-toc-title)

The Content Board screen in [PublishPress Planner](https://publishpress.com/links/planner) allows you to use a kanban board layout to organize your WordPress content. The Content Board screen allows you to see content organized by status.

## Introducing the Content Board Screen [#](#0-toc-title)

By default the Content Screen screen provides 4 filters and 4 card details. Each post on this screen is referred to as a “card”.

- **Default filters**: Date, Post Status, Author, Post Type.
- **Default card details**: Post Date, Title, Post Type, Author

You can customize the columns and card details that are used on this screen. [Here is our guide to custom filters](https://publishpress.com/knowledge-base/filters-in-content-board/) and [here is our guide to custom card details](https://publishpress.com/knowledge-base/card-data-in-content-board/).

![Content Board screen](https://docs-media.publishpress.com/publishpress-planner/content-board-screen-2d0fe1e11f.webp)

You can use this screen, you drag-and-drop the posts to change their status. In the image below, we’re moving a post from the “Draft” status to the “Pending Review” status.

![Change post status](https://docs-media.publishpress.com/publishpress-planner/change-status-4592120b9c.webp)

You can move posts to any status including the “Scheduled” status. If you move a post to the “Scheduled” status, it will automatically be given the date chosen in the “Default Date” setting, as in this screenshot below.

![](https://docs-media.publishpress.com/publishpress-planner/scheduled-status-fd35676d6e.webp)

If you want to add more statuses, this is possible with the [PublishPress Statuses](https://publishpress.com/links/statuses) plugin. If you have more statuses than appear on the screen, there will be a horizontal scrollbar, as in this screenshot below.

![PublishPress Statuses and the Content Board](https://docs-media.publishpress.com/publishpress-planner/statuses-kanban-5d110ac2b9.webp)

Once you have created the layout you need, there is also a “Print button available so you can print a copy of all your planned content.

![Content Board Print Screen](https://docs-media.publishpress.com/publishpress-planner/content-board-screen-print-c84f2729f3.webp)

## The Modal Editing Window [#](#1-toc-title)

This feature requires the Pro version of the PublishPress Planner plugin.

If you’re using the Pro version of [PublishPress Planner](https://publishpress.com/links/planner), you can click on any post and see a larger modal that allows you to edit many details of each post:

![Modal window in the Content Board](https://docs-media.publishpress.com/publishpress-planner/large-planner-modal-809346c58e.webp)

## Content Board Default Settings [#](#1-toc-title)

You can change what post types are visible by default on this screen by going to Planner > Settings > Content Board

![Content Board settings](https://docs-media.publishpress.com/publishpress-planner/content-board-settings-d25d374ac5.webp)
