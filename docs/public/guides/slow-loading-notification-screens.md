# Slow Notification Screens in PublishPress Planner

Some big sites have problems with the PublishPress Notification screens loading slowly. This can happen if you have many taxonomy terms.

You can stop those terms from loading by going to PublishPress > Settings > Notifications and entering some of the Taxonomy slugs into the box, “Blacklisted taxonomies for Notifications”.
