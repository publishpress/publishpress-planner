# Shortcodes Aren’t Working in Planner Emails

If shortcodes are not loading in your [PublishPress Planner](https://publishpress.com/links/planner) notification emails, first [follow this guide to make sure they are set up correctly.](https://publishpress.com/docs/customize-email-notifications/)

Next, click the “Text” tab and check that the shortcodes are entered cleanly and are not surrounded by any HTML code:
