# Getting Started with Planner Notifications

This screen allows you to send email notifications of all important changes to content on your WordPress site. The feature is designed to send notifications to the content creators and editors on your site. We don’t recommend using this feature to send email to a large number of users.

This image below shows the main screen for notifications in [PublishPress Planner](https://publishpress.com/links/planner). We provide two default notifications:

- **Notify when content is published**. This will contact Site Administrators when new content is published.
- **Notify on editorial comments**. This will contact Site Administrators when new [editorial comments](https://publishpress.com/knowledge-base/start-editorial-comments/) are published.

![PLanner notifications](https://docs-media.publishpress.com/publishpress-planner/notifications-screen-32da729e16.webp)

It’s possible to create your own notifications and customize them in depth. Start learning more with these two guides to Notifications:

- [Click here for more on the Notification Options](https://publishpress.com/knowledge-base/understanding-notification-workflow-screen/).
- [Click here to see how to customize the Notifications](https://publishpress.com/knowledge-base/customize-email-notifications/).
