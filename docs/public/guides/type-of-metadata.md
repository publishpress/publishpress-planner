# Types of Editorial Fields in PublishPress Planner

Table of Contents

- [Checkbox](#h-checkbox)
- [Dropdown Select](#h-dropdown-select)

- [Location](#h-location)
- [Number](#h-number)

There are eight types of fields available in [PublishPress Planner](https://publishpress.com/links/planner):

- Checkbox
- Dropdown Select
- Date
- Location
- Number
- Paragraph
- Text
- User

![PublishPress Planner metadata types](https://docs-media.publishpress.com/publishpress-planner/metadata-types-e8f16dca00.webp)

## Checkbox [#](#h-checkbox)

The “Checkbox” option provides a simple box that can be checked by users editing a post. In the image below, you can see a “Checkbox” example called “Approved by Legal Team”.

![PublishPress Planner checkbox metadata](https://docs-media.publishpress.com/publishpress-planner/checkbox-admin-427dcd3677.webp)

## Dropdown Select [#](#h-dropdown-select)

The “Dropdown Select” option provides either a single or multiple choices. In the image below, you can see a “Dropdown Select” example called “Type of Story”.

![PublishPress Planner Dropdown Select metadata](https://docs-media.publishpress.com/publishpress-planner/dropdown-select-admin-e77fc73ca8.webp)

## Date [#](#h-date)

The “Date” option provides a date picker. In the image below, you can see a “Date” example called “First Draft Date”.

![PublishPress Planner Date metadata](https://docs-media.publishpress.com/publishpress-planner/date-field-30fd89187b.webp)

## Location [#](#h-location)

The “Location” option provides an area to the name of a location, or an address. This field will automatically turn the field into a Google Maps link. In the image below, you can see a “Location” example called “Report Location”.

![PublishPress Planner Location metadata](https://docs-media.publishpress.com/publishpress-planner/location-field-2113d32f75.webp)

## Number [#](#h-number)

The “Number” option provides an area to enter numerals. In the image below, you can see a “Number” example called “ISBN Number”.

![PublishPress Planner Number metadata](https://docs-media.publishpress.com/publishpress-planner/number-field-27bc80d759.webp)

## Paragraph [#](#h-paragraph)

The “Paragraph” option provides a text area with several rows. In the image below, you can see a “Paragraph” example called “Assignment”.

![PublishPress Planner Paragraph metadata](https://docs-media.publishpress.com/publishpress-planner/assignment-field-6e4c3ddfa8.webp)

## Text [#](#h-text)

The “Text” option provides a single text row. In the image below, you can see a “Text” example called “Publisher Name”.

![PublishPress Planner Text metadata](https://docs-media.publishpress.com/publishpress-planner/text-field-1a4db1801f.webp)

## User [#](#h-user)

The “User” option provides the ability to select a WordPress users. In the image below, you can see a “User” example called “Copy Editor for this post”.

![PublishPress Planner user metadata](https://docs-media.publishpress.com/publishpress-planner/user-field-34a25fbfd1.webp)
