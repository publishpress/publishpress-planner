# The Content Overview Screen

Table of Contents

- [Introducing the Content Overview Screen](#0-toc-title)
- [The Modal Editing Window](#1-toc-title)
- [Content Overview Default Settings](#2-toc-title)

The Content Overview screen is a companion to [the PublishPress Planner Calendar screen](https://publishpress.com/publishpress/docs/calendar/). The Calendar allows you to see content organized by dates. The Content Overview screen allows you to drill down and see content organized by status, categories, authors and much more.

## Introducing the Content Overview Screen [#](#0-toc-title)

By default the Content Overview screen provides 5 filters and 6 columns.

- **Default filters**: Date, Post Status, Categories, Author, Post Type.
- **Default columns**: Title, Status, Post Type, Author, Post Date, Last Modified

You can customize the columns and filters that are used on this screen. [Here is our guide to custom columns](https://publishpress.com/knowledge-base/columns-in-content-overview/) and [here is our guide to custom filters](https://publishpress.com/knowledge-base/filters-content-overview/).

![Content Overview screen in PublishPress Planner](https://docs-media.publishpress.com/publishpress-planner/content-overview-71fa215723.webp)

*Content Overview Screen*

There is a “Me Mode” available on this screen. When you enable the Me Mode, you will only see posts where you are the author.

![Me Mode in PublishPress Planner](https://docs-media.publishpress.com/publishpress-planner/me-mode-0207f6472c.webp)

*Content Overview Metadata*

There is also a “Print” button available so you can print a copy of all your scheduled content.

![Print button for Content Overview screen](https://docs-media.publishpress.com/publishpress-planner/print-content-overview-c82559475b.webp)

## The Modal Editing Window [#](#1-toc-title)

This feature requires the Pro version of the PublishPress Planner plugin.

If you’re using the Pro version of [PublishPress Planner](https://publishpress.com/links/planner), you can click on any post and see a larger modal that allows you to edit many details of each post:

![Modal window in the Content Overview](https://docs-media.publishpress.com/publishpress-planner/large-planner-modal-809346c58e.webp)

## Content Overview Default Settings [#](#2-toc-title)

You can change what post types are visible by default on this screen by going to Planner > Settings > Content Overview.
