# How Users Can Control Their Own Slack Notifications (Pro)

This feature requires the Pro version of the PublishPress Planner plugin.

If you have the [PublishPress Planner](https://publishpress.com/links/planner) plugin installed on your site, users can control where they receive their notifications.

If users go to their user profile, they can scroll down to the “Editorial Notifications” area. Here they can choose different Slack channels for each [notification workflow](https://publishpress.com/docs/notifications/):
