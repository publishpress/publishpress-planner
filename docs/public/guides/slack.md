# Getting Started With Slack Notifications (Pro)

This feature requires the Pro version of the PublishPress Planner plugin.

[PublishPress Planner](https://publishpress.com/links/planner) Pro allows you to send notifications to your Slack account. Each notification will be triggered by a [notification workflow](https://publishpress.com/docs/notifications/).

The image below shows an example Slack notification. The main text is controlled by the “Notifications” area inside the [PublishPress Planner](https://publishpress.com/links/planner) plugin in your WordPress site.

You can also see “Comment”, “Edit” and “View” links for quick access to your content.

![Slack Notification](https://docs-media.publishpress.com/publishpress-planner/slack-notification-d83dea12d6.webp)
