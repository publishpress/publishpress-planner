# How to Use Slack Mentions in Notifications (Pro)

This feature requires the Pro version of the PublishPress Planner plugin.

With [PublishPress Planner](https://publishpress.com/links/planner) Pro, can you use Slack notifications and take advantage of Slack’s mentions feature.

You can use mentions by adding this to your notifications:

```
@UAFBXS515
```

You should replace `UAFBXS515` with the Slack user’s ID

To find a Slack user ID, follow these steps:

1. Click on a user name within Slack.
2. Click on “View profile” in the menu that appears.
3. Click the more icon “…”
4. Click on “Copy Member ID.”
