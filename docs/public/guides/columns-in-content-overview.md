# Columns in Content Overview

Table of Contents

- [Introducing Content Overview Columns](#0-toc-title)
- [How to Add Columns](#1-toc-title)
- [How to Add Columns (Pro)](#2-toc-title)

The [Content Overview](https://publishpress.com/links/content-overview) Screen is available in the [PublishPress Planner](https://publishpress.com/links/planner) plugin. This screen gives you an overview of all the content on your site. You can choose the data to see for your posts. This data appears in columns.

## Introducing Content Overview Columns [#](#0-toc-title)

There are 6 default columns on this screen: Title, Status, Post Type, Author, Post Date, Last Modified. You can see those columns in this screenshot:

![Content Overview screen columns](https://docs-media.publishpress.com/publishpress-planner/content-overview-71fa215723.webp)

## How to Add Columns [#](#1-toc-title)

It is possible to customize the columns on this screen. Click the “Customize Columns” button:

![Custom columns on Content Overview](https://docs-media.publishpress.com/publishpress-planner/customize-content-overview-1-15a5a0ff0e.webp)

In the modal, you can check or uncheck the boxes for all the inbuilt columns.

![Column selection on the Content Overview screen](https://docs-media.publishpress.com/publishpress-planner/customize-columns-1-b55baae212.webp)

In this screenshot below, you can see columns for Editorial Fields and Taxonomies. If you click any of these elements, they will be added as new columns on your [Content Overview](https://publishpress.com/links/content-overview) screen.

![Editorial Fields and Taxonomies](https://docs-media.publishpress.com/publishpress-planner/fields-taxonomies-1e3cb0073f.webp)

## How to Add Columns (Pro) [#](#2-toc-title)

This feature requires the Pro version of the PublishPress Planner plugin.

The Pro version of [PublishPress Planner](https://publishpress.com/links/planner) has integrations with plugins that include Yoast SEO and [PublishPress Checklists](https://publishpress.com/links/checklists). In the screenshot below, you can see that those options are ready to be checked.

![New columns for Content Overview](https://docs-media.publishpress.com/publishpress-planner/new-filters-overview-3206bb2ffa.webp)

In this screenshot below, we’ve added one column from [PublishPress Checklists](https://publishpress.com/links/checklists) and also the “SEO score” column from Yoast SEO.

![Content Overview with filters](https://docs-media.publishpress.com/publishpress-planner/content-overview-filters-f3b7b0df45.webp)

## How to Add Custom Columns [#](#3-toc-title)

The Content Overview screen allows you to add custom columns. These columns can use any metadata stored on your site by WordPress plugins.

- Click the “Customize Columns” button.
- Click the “Add New” button.

![Adding a new custom column](https://docs-media.publishpress.com/publishpress-planner/add-new-column-8d15692793.webp)

- Enter a “Column Title”.
- Click the “Select Metakey” option.
- In this screenshot below, we are selecting the “_yoast_wpseo_focuskw” option. This will show the keyword from the Yoast SEO plugin.
- Click “Add Column”.
- Click “Apply Changes”.

![Selecting a metakey in the Content Overview screen](https://docs-media.publishpress.com/publishpress-planner/yoast-keyword-content-overview-1-317e79e665.webp)

You will now see the “Yoast Keyword” column has been added to the screen, as in this screenshot below:

![new columns on the Content Overview screen](https://docs-media.publishpress.com/publishpress-planner/content-overview-new-column-1-4bd3bcde92.webp)

## How to Reorder Columns [#](#4-toc-title)

It is possible to change the order of columns in the Content Overview screen

- Click “Customize Columns”.
- Click the “Reorder Columns” tab.
- You can drag-and-drop the columns into a new order.

![Reorder Columns in the Content Overview](https://docs-media.publishpress.com/publishpress-planner/reorder-columns-1a1602ca28.webp)
