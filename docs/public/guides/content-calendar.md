# The Content Calendar Screen

Table of Contents

- [How the Content Calendar Works](#0-toc-title)
- [Create Content From the Calendar](#h-create-content-from-the-calendar)
- [The Content Calendar Settings](#h-the-publishpress-planner-calendar-settings)

Using the Content Calendar, you can easily see when content is planned, and when it was published. You can also drag-and-drop content to a new publication date.

## How the Content Calendar Works [#](#0-toc-title)

The calendar gives you a powerful overview of your publishing schedule. By default, you see all the content you have planned for the next five weeks. If you need to drill down, you can filter the calendar by post status, categories, users or post types.

You can drag-and-drop your content to a new publication date.

![](https://docs-media.publishpress.com/publishpress-planner/content-calendar-4ea0fe7f28.webp)

*Calendar Main Screen*

If you’re using the free version of [PublishPress Planner](https://publishpress.com/links/planner) click on a content title, you’ll see a pop-up with details about that content item. You can edit the content, trash it, view it, or use the “follow” feature in [PublishPress Planner](https://publishpress.com/links/planner).

![WordPress Planner modal](https://docs-media.publishpress.com/publishpress-planner/about-wordpress-a273e7f3db.webp)

*Calendar Popup*

This feature requires the Pro version of the PublishPress Planner plugin.

If you’re using the Pro version of PublishPress Planner, you’ll see a much larger modal that allows you to edit many details of each post:

![Large WordPress Planner modal](https://docs-media.publishpress.com/publishpress-planner/large-planner-modal-809346c58e.webp)
