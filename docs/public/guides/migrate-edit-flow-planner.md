# How to Migrate Edit Flow to PublishPress Planner

PublishPress is based on the Edit Flow plugin. So it is easy to import your data and settings.

- Start your site with Edit Flow installed.
- Install the PublishPress plugin.
- You will now see this message that Edit Flow was deactivated. Click “Yes, import the data”.

![Import Editflow](https://docs-media.publishpress.com/publishpress-planner/import-editflow-79c2e89ef4.webp)

*Import Editflow*

- The next screen will look like the image below. Click “Start”:

![Import Edit Flow](https://docs-media.publishpress.com/publishpress-planner/import-edit-flow-50e470dbea.webp)

*Import Edit Flow*

- After the process is complete, you will see the message below, and you can start using PublishPress.

![Finished Import](https://docs-media.publishpress.com/publishpress-planner/finished-import-00f64b09ae.webp)

*Finished Import*
