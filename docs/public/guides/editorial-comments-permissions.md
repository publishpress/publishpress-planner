# Editorial Comments Permissions

Please note: This feature is now deprecated because Editorial Comments are being added to the WordPress core.

There are four permissions that you can use to control Editorial Comments in [PublishPress Planner](https://publishpress.com/links/planner).

Two permissions control who can delete comments:

- pp_delete_editorial_comment
- pp_delete_others_editorial_comment

Two permissions control who can edit comments:

- pp_edit_editorial_comment
- pp_edit_others_editorial_comment

You can manage these using the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin. After installation, go to “Capabilities” in your admin menu and look for the “[PublishPress Planner](https://publishpress.com/links/planner)” tab.
