# Getting Started with PublishPress Planner

Table of Contents

- [Install the Free version of PublishPress Planner](#h-install-the-free-version-of-publishpress-planner)

[PublishPress Planner](https://publishpress.com/links/planner) is the plugin for managing and scheduling WordPress content.

This is a guide to installing the [PublishPress Planner](https://publishpress.com/links/planner) plugin. These guides have useful background information as you’re getting started:

- [Technical requirements for our plugins](https://publishpress.com/knowledge-base/technical-requirements/).
- [How to move from Free to Pro plugins](https://publishpress.com/knowledge-base/how-to-move-from-free-to-pro-plugins/).

## Install the Free version of PublishPress Planner [#](#h-install-the-free-version-of-publishpress-planner)

- Log in to your WordPress dashboard.
- Go to “Plugins”, then “Add New”.
- Search for “PublishPress Planner”.
- You will see the image below as a result. Click “Install Now”.

![PublishPress Planner install](https://docs-media.publishpress.com/publishpress-planner/publishpress-planner-install-fa62287897.webp)

- Click “Activate”.
- You will now see Planner in your WordPress admin menu.

![PublishPress Planner menu](https://docs-media.publishpress.com/publishpress-planner/planner-menu-7c43fc306c.webp)

*Publishpress Planner Free*
