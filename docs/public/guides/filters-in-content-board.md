# Filters in Content Board

The [Content Board](https://publishpress.com/links/content-board) Screen is available in the [PublishPress Planner](https://publishpress.com/links/planner?swcfpc=1) plugin. This screen gives you an overview of the content on your site. You can choose the data to see for your posts and also choose how this data is filtered.

## Introducing Content Overview Filters [#](#0-toc-title)

There are four default columns on this screen: Date, Post Status, Author, and Post Type. You can see those filters in this screenshot:

![Content Board Screen](https://docs-media.publishpress.com/publishpress-planner/content-board-screen-2d0fe1e11f.webp)

## How to Add Filters [#](#1-toc-title)

It is possible to customize the filters on this screen. Click the “Customize Filters” button:

![Customize Content Board filters](https://docs-media.publishpress.com/publishpress-planner/board-filters-303a37f09a.webp)

In the modal, you can check or uncheck the boxes for all the inbuilt filters.

![Filters in Content Board](https://docs-media.publishpress.com/publishpress-planner/board-filters-modal-e80cd02911.webp)

In this screenshot below, you can see filters for Editorial Fields and Taxonomies. If you click any of these elements, they will be added as new filters on your [Content Board](https://publishpress.com/links/content-board) screen. In this screenshot below, we’re adding a new filter for “Categories”.

![Content Board screen filters](https://docs-media.publishpress.com/publishpress-planner/taxonomies-filter-ae3f56ba95.webp)

If you choose to add a “Categories” filter, you will see be able to use that option to filter posts on the Content Board. In this screenshot below, you can choose to see only the posts with a specific Category.

![New category filter](https://docs-media.publishpress.com/publishpress-planner/categories-filter-b2d940e2f6.webp)

## How to Add Custom Filters [#](#2-toc-title)

The [Content Overview](https://publishpress.com/links/content-overview) screen allows you to add custom filters. These filters can use any metadata stored on your site by WordPress plugins. In this example, we’ll use data from the Rank Math SEO plugin.

- Click the “Customize Filters” button.
- Click the “Add New” button.

![Add new custom filters](https://docs-media.publishpress.com/publishpress-planner/add-new-filters-db827a1c51.webp)

- Enter a “Column Title”.
- Click the “Select Metakey” option.
- In this screenshot below, we are selecting the “rank_math_seo_score” option. This will allow you to filter for SEO scores as calculated by the Rank Math plugin.
- Click “Add Filter”.
- Click “Apply Changes”.

![Adding a Rank Math filter](https://docs-media.publishpress.com/publishpress-planner/rank-math-seo-80e2bfe73d.webp)

You will now see the “Rank Math Score” column has been added to the screen, as in this screenshot below:

![Rank Math Filter](https://docs-media.publishpress.com/publishpress-planner/rank-math-filter-b51dcf4c84.webp)

## How to Add Custom Filters (Pro) [#](#3-toc-title)

This feature requires the Pro version of the PublishPress Planner plugin.

The Pro version of [PublishPress Planner](https://publishpress.com/links/planner) has automatic support for plugins that include Yoast SEO and [PublishPress Checklists](https://publishpress.com/links/checklists). In the screenshot below, you can see that those options are ready to be checked.

![Yoast SEO and Checklists ](https://docs-media.publishpress.com/publishpress-planner/automatic-filters-e5b25a1c31.webp)

## How to Reorder Filters [#](#4-toc-title)

It is possible to change the order of filters in the [Content Overview](https://publishpress.com/links/content-overview) screen

- Click “Manage Filters”.
- Click the “Reorder Filters” tab.
- You can drag-and-drop the filters into a new order.

![Reorder Content Overview Filters](https://docs-media.publishpress.com/publishpress-planner/reorder-filters-edd1714a78.webp)
