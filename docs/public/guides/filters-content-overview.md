# Filters in Content Overview

Table of Contents

- [Introducing Content Overview Filters](#0-toc-title)
- [How to Add Filters](#1-toc-title)
- [How to Add Filters (Pro)](#2-toc-title)
- [How to Add Custom Filters](#1-toc-title)

The [Content Overview](https://publishpress.com/links/content-overview) Screen is available in the [PublishPress Planner](https://publishpress.com/links/planner) plugin. This screen gives you an overview of all the content on your site. You can choose the data to see for your posts and also choose how this data is filtered.

## Introducing Content Overview Filters [#](#0-toc-title)

There are 6 default columns on this screen: Date, Post Status, Categories, Author, and Post Type. You can see those filters in this screenshot:

![Content Overview screen](https://docs-media.publishpress.com/publishpress-planner/content-overview-update-c21ea902c0.webp)

## How to Add Filters [#](#1-toc-title)

It is possible to customize the filters on this screen. Click the “Manage Filters” button:

![Content Overview filters](https://docs-media.publishpress.com/publishpress-planner/overview-filters-f5a90dfef4.webp)

In the modal, you can check or uncheck the boxes for all the inbuilt filters.

![Content Overview filters modal](https://docs-media.publishpress.com/publishpress-planner/overview-fields-ca4093bcfc.webp)

In this screenshot below, you can see filters for Editorial Fields and Taxonomies. If you click any of these elements, they will be added as new filters on your [Content Overview](https://publishpress.com/links/content-overview) screen.

![Content Overview filter](https://docs-media.publishpress.com/publishpress-planner/overview-filters-enable-9253084b33.webp)

## How to Add Filters (Pro) [#](#2-toc-title)

This feature requires the Pro version of the PublishPress Planner plugin.

The Pro version of [PublishPress Planner](https://publishpress.com/links/planner) has automatic support for plugins that include Yoast SEO and [PublishPress Checklists](https://publishpress.com/links/checklists). In the screenshot below, you can see that those options are ready to be checked.

![Add new filters](https://docs-media.publishpress.com/publishpress-planner/checklists-filters-4ca7dfcd4c.webp)

In this example screenshot below, we’ve added a filter from [PublishPress Checklists](https://publishpress.com/links/checklists). You can use the filter to find all posts that have either “Passed” or “Failed” that checklist requirement.

![Content Overview with checklists](https://docs-media.publishpress.com/publishpress-planner/new-filter-600ad28d2e.webp)

## How to Add Custom Filters [#](#1-toc-title)

The Content Overview screen allows you to add custom filters. These filters can use any metadata stored on your site by WordPress plugins.

- Click the “Manage Filters” button.
- Click the “Add New” button.

![Add new custom filters](https://docs-media.publishpress.com/publishpress-planner/add-new-filters-db827a1c51.webp)

- Enter a “Column Title”.
- Click the “Select Metakey” option.
- In this screenshot below, we are selecting the “_yoast_wpseo_focuskw” option. This will allow you to filter for keywords from the Yoast SEO plugin.
- Click “Add Filter”.
- Click “Apply Changes”.

![](https://docs-media.publishpress.com/publishpress-planner/add-new-filter-fd1a5bf53f.webp)

You will now see the “Yoast Keyword” column has been added to the screen, as in this screenshot below:

![New filter on Content Overview screen](https://docs-media.publishpress.com/publishpress-planner/yoast-keyword-filter-630d6173bf.webp)

## How to Reorder Filters [#](#2-toc-title)

It is possible to change the order of filters in the Content Overview screen

- Click “Manage Filters”.
- Click the “Reorder Filters” tab.
- You can drag-and-drop the filters into a new order.

![Reorder Content Overview Filters](https://docs-media.publishpress.com/publishpress-planner/reorder-filters-edd1714a78.webp)
