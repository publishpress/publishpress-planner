# Who Can Edit Fields in PublishPress Planner

Editorial Fields is the extra information that you can add to guide the creation of posts. For example, the editor of a site can set a First Draft Date and enter Assignment details. Here’s an example:

![Editorial fields in a metabox](https://docs-media.publishpress.com/publishpress-planner/metadata-example-9c760de65e.webp)

However, you wouldn’t want your content creators to edit this metadata. After all, if they’re running behind schedule they could move their deadlines and change their assignments!

So, with the [PublishPress Capabilities](https://publishpress.com/links/capabilities) plugin, you can decide which user groups can edit fields:

- Go to the “Capabilities” screen.
- Click the “[PublishPress Planner](https://publishpress.com/links/planner)” tab.
- Check the “edit metadata” box the role you want to edit fields.
